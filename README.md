# 📧 mexporter: Как забрать свою почту из Mail.ru / VK WorkSpace

Mail.ru отключил бесплатный доступ к IMAP/POP3 и значительно поднял цены на хостинг почты. Если вы хотите перенести свои письма на собственный домен или VPS, но не знаете, как их выгрузить — **эта программа создана именно для вас**.

Она бережно скачает все ваши письма на компьютер в универсальном формате, чтобы вы могли загрузить их на любой новый почтовый сервер.

> 🛡 **Это безопасно:** Программа работает **только в режиме чтения**. Она не удаляет, не перемещает и не изменяет ваши письма. Ваши пароли нигде не сохраняются: программа использует временный ключ входа, точно так же, как это делает ваш браузер.

---

## 🚀 Быстрый старт (займёт 3 минуты)

Вам не нужно быть программистом или что-то устанавливать. Всё уже готово к работе.

### Шаг 1. Скачайте программу
1. Перейдите на страницу [GitHub Releases](https://github.com/hzcht/escape-mailru/releases).
2. Скачайте архив для вашей системы:
    - **Windows:** `mexporter-vX.X.X-windows-x64.zip`
    - **macOS / Linux:** `mexporter-vX.X.X-linux-x64.tar.gz` (или аналогичный)
3. Распакуйте архив в любую удобную папку (например, на Рабочий стол или в `C:\mexporter`).

### Шаг 2. Разрешите программе доступ к почте (делается 1 раз)
Программа представится почтовому серверу от вашего имени — под вашим аккаунтом Mail.ru или VK WorkSpace.
1. Откройте папку, куда вы распаковали программу.
2. **Для Windows:** кликните на пустое место в адресной строке папки (сверху, где написан путь), сотрите всё, напишите `cmd` и нажмите **Enter**. Откроется чёрное окно (терминал).  
   *(Для macOS/Linux: откройте "Терминал" и перетащите файл программы в это окно)*.
3. Вставьте эту команду и нажмите **Enter**:

        # Для Windows:
        mexporter.exe -init-session
        
        # Для macOS / Linux:
        ./mexporter -init-session

4. Автоматически откроется ваш браузер. Войдите в свой почтовый ящик, как обычно.
5. Когда почта загрузится, вернитесь в чёрное окно и нажмите **Enter**. Программа всё сделает сама и сохранит безопасный ключ доступа в папку `session`.

### Шаг 3. Скачайте письма
Просто запустите программу (дважды кликните по `mexporter.exe` или введите `./mexporter` в терминале).
1. Вы увидите список ваших папок (Входящие, Отправленные и т.д.).
2. Используйте **стрелки** на клавиатуре для перемещения.
3. Нажимайте **Пробел**, чтобы отметить нужные папки (рядом появится галочка `✓`).
4. Нажмите **Enter**, чтобы начать скачивание.

> 💡 **Если интернет пропал или вы закрыли окно:** Ничего страшного! Просто запустите программу снова. Она умная: проверит, что уже скачано, и продолжит с того же места, не скачивая одно и то же дважды.

## 📂 Что я получу в итоге?

В папке с программой появится папка `mail-export`. Внутри неё будет аккуратная структура:

    mail-export/
    └── vash_email@mail.ru/
        ├── Входящие/
        │   ├── 2023-10-25_Тема_письма_12345.eml
        │   └── 2023-10-26_Другое_письмо_67890.eml
        └── Отправленные/
            └── ...

Каждый файл `.eml` — это одно ваше письмо. Этот формат понимают абсолютно все почтовые программы (Outlook, Thunderbird, The Bat!) и почтовые серверы.

**Что делать дальше?** После скачивания вы можете загрузить эти файлы на новый сервер с помощью нашего простого скрипта: [Инструкция по переносу на IMAP](scripts/README.md).

## ❓ Частые вопросы и решение проблем

**Программа пишет "authorization failed" или "Ошибка 2"**  
Ваш временный ключ входа истёк (Mail.ru иногда их обновляет). Это нормально. Просто введите в терминале:  
`mexporter.exe -refresh-session`  
Если не помогло, введите `mexporter.exe -init-session -force` и войдите в браузер заново.

**Я боюсь что-то сломать. Можно сначала "протестировать"?**  
Да! Добавьте к запуску флаг `-dry-run`. Программа покажет список писем, которые она *собралась* скачать, но ничего реально скачивать не будет:  
`mexporter.exe -dry-run`

**Как проверить, что все письма скачались целыми?**  
Запустите программу с флагом проверки. Она сверит файлы на диске с журналом скачивания:  
`mexporter.exe -verify`

**Можно ли скачать только 10 писем для проверки?**  
Да, используйте флаг `-limit`. Например:  
`mexporter.exe -limit 10`

## ⚙️ Для продвинутых пользователей

Если вы хотите тонко настроить процесс, вы можете использовать дополнительные параметры при запуске или отредактировать файл `mexporter.json` (он создаётся автоматически).

| Параметр | Что делает | Пример |
| :--- | :--- | :--- |
| `-no-tui` | Отключает интерактивное меню. Берёт папки из файла настроек `mexporter.json`. | `mexporter.exe -no-tui` |
| `-folders 0,1` | Скачивает только папки с указанными номерами (номера видны при `-list`). | `mexporter.exe -folders 0,2` |
| `-workers 8` | Увеличивает количество одновременных загрузок (по умолчанию 4). Будьте осторожны, слишком большое число может привести к временной блокировке со стороны Mail.ru. | `mexporter.exe -workers 8` |
| `-delay 500ms` | Добавляет паузу в 500 миллисекунд между запросами для максимальной безопасности. | `mexporter.exe -delay 500ms` |
| `-out C:\MyMail` | Сохраняет письма в указанную вами папку, а не в `mail-export`. | `mexporter.exe -out C:\MyMail` |
| `-list` | Просто показывает список папок и их номера, затем закрывается. | `mexporter.exe -list` |

*(Полный список технических флагов доступен по команде `mexporter -h` — для Windows: `mexporter.exe -h`)*

## 🔒 Конфиденциальность

- Программа имеет **открытый исходный код**. Вы можете проверить её код на GitHub.
- Файл `session/session.json` содержит только временные технические ключи (cookie), а не ваш пароль. **Не передавайте этот файл никому.**
- Программа игнорирует все cookie, кроме принадлежащих доменам `mail.ru`, `vk.com` и `vk.ru`.

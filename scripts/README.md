# Скрипты миграции почты

## migrate_to_imap.py

Скрипт для переноса локальных `.eml` файлов на IMAP-сервер.

### Особенности
- Поддержка SSL (port 993) и нешифрованного соединения (port 143)
- Автоматический парсинг заголовков и тела письма из `.eml` файлов
- Итеративная загрузка с отслеживаемым прогрессом
- Гибкая конфигурация через JSON-файл или аргументы командной строки

### Требования
- Python 3 (все используемые модули входят в стандартную библиотеку)
- Доступ к IMAP-серверу (порт 993 SSL или 143 plain)

### Установка и запуск

1. **Подготовка**
   - Положите `.eml` файлы в указанную папку (или подкаталог).
   - Узнайте свои данные для входа на IMAP-сервер (логин, пароль, порт).

2. **Конфигурация**
   Либо создайте файл `scripts/config.json` с полями:
   ```json
   {
     "server": "imap.spaceweb.ru",
     "port": 993,
     "login": "your_email@domain.ru",
     "password": "your_password",
     "eml_folder": "C:\\Path\\To\\EML\\Folder"
   }
   ```
   Или передавайте параметры напрямую через командную строку.

3. **Запуск**
   ```powershell
   cd E:\proj\mexporter\scripts
   python migrate_to_imap.py
   ```
   Или с явными параметрами:
   ```powershell
   python migrate_to_imap.py --server imap.spaceweb.ru --port 993 --login user@domain.ru --password --folder "C:\mails\eml"
   ```

### Возможные проблемы
- **Сложные многокомпонентные письма**: скрипт извлекает `text/plain` часть. Если в письме только `text/html`, тело может быть пустым.
- **Кодировка**: скрипт пытается определить кодировку автоматически, для русскихSubject/Body может потребоваться настройка локали.
- **Флгасы прочитанного**: по умолчанию ставится `\Seen`. Можно изменить в коде функции `upload_message`.
- **Лимит скорости IMAP**: если сервер ограничивает количество операций в минуту, можно увеличить `time.sleep(0.1)` в коде.
